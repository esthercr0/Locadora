# Wireframes da locadora

Protótipo navegável de média/alta fidelidade aprovado pela aluna em 22/11/2026.

Abra [index.html](index.html) após baixar o arquivo, ou abra-o diretamente no navegador a partir da cópia local do repositório. Este arquivo é independente e não precisa de servidor.

O protótipo cobre visão geral, Fabricantes, Categorias, Veículos, Clientes, Aluguéis, registro de devolução e as cinco consultas da primeira parte. Inclui formulários de cadastro/edição, detalhes, confirmação de exclusão, pesquisa em múltiplos campos e estados de lista vazia.

Os registros são ilustrativos e existem apenas na memória da página. O front-end integrado fica em `frontend/` e consulta a API real. O protótipo não constitui evidência de persistência no SQL Server.

Link permanente para o artefato no GitHub: https://github.com/esthercr0/Locadora/blob/frontend/etapa-1/Docs/Wireframes/index.html
